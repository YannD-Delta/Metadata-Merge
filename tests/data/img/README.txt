Small real image files for the header-parser tests.
png/jpeg/gif/bmp/ico: made by tools/make-test-images.ps1 (System.Drawing).
webp-vp8x-header.bin: the first 64 bytes (RIFF + VP8X chunk header, no picture data) of a real WebP screenshot.
The 1x1 lossy, lossless and extended WebP files are inline in the tests (the standard WebP feature-detection files).
